# about.metermatters.app

The front page for [Meter Matters](https://metermatters.app), served by GitHub
Pages. Plain HTML and CSS, no build step: edit a file, push, and it's live in
about a minute.

- `index.html`, `privacy.html`, `styles.css`, `icon.svg`
- `img/` screenshots of the app on an invented household (no real bills)
- `video/demo.mp4` the one-minute walkthrough, and its poster frame
- `CNAME` tells GitHub Pages which domain this is

The app itself lives in [davidfic/meter-matters](https://github.com/davidfic/meter-matters).
